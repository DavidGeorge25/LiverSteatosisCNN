## "Why isn't that white circle outlined?"

The first question anyone asks. Run `why_unlabeled.py <tile-id>` to get the
answer per region; it attributes every unlabeled white component to the filter
that dropped it. For the moderate panel:

| | count |
| --- | --- |
| white components in the tile | 86 |
| below the 40 µm² macro floor → microvesicular, **excluded by design** | 47 |
| macro-sized, accepted | 35 |
| macro-sized, rejected | 4 (one vessel at 8,268 µm², three ragged/elongated fragments < 60 µm²) |
| rejected components ≥ 150 µm² that are actually round | **0** |

So most unoutlined white in any panel is sub-floor microvesicular clearing, which
is a stated scope limit rather than a miss (§9). The macro-sized rejections are
the price of the `max_eccentricity` ceiling added in revision 2, and that price is
quantified in `configs/tuned.yaml`: it costs 6–10% of MASH signal uniformly across
severity, and removes 40–64% of CCl₄ false positives. Conservative on purpose.

## What these figures do and do not support

Safe to claim:

- Pseudo-labels are generated **without any manual annotation**.
- **Specificity is measured**, not asserted: 0.17% mean fat area on a cohort
  known to be fat-free, worst slide 0.44% (`outputs/batch_CCl4_tuned2.csv`).
- **Perfect slide-level separation** of the two cohorts, which survives 200
  held-out splits (`outputs/holdout_repeats.csv`).
- Labels carry a **per-pixel confidence** map usable as a loss weight.

Not supported by anything here — do not put these in the grant:

- Any accuracy figure (Dice/IoU/precision/recall). There is no reference
  segmentation, so none can be computed.
- Absolute fat percentages as calibrated measurements. The parameter sweep moves
  cohort mean fat over 6.82–10.91%, and an individual slide over 1.67–5.16%
  (3.1×), while separation stays saturated at AUC 1.000. Slide-resampled mean is
  9.4%, 95% CI [7.18, 11.40].
- **Fold-changes.** Ordinal comparisons survive the sweep — slide rank order
  holds at Spearman ρ ≥ 0.912 across all 64,620 pairs of the 360 parameter cells
  (mean 0.973). Ratios do not: the R25-264-12 vs R25-264-34 difference is 3.2×
  under one cell and 6.8× under another, and the cohort MASH:control contrast
  ranges 15:1 to 150:1. Say "ranks higher than", not "3× more than".
- Sensitivity. The negative control bounds false positives only; there is no way
  here to measure what the pipeline misses.
- Microvesicular steatosis. Measured but excluded from labels — it separates the
  cohorts only ~1.4:1. **Scope is macrovesicular only** and should be stated.

Full detail in `../LIMITATIONS.md`.

# Validation figures — nine batches and the diet contrast

Generated by `make_validation_figures.py` from `outputs/survey_9batches.csv`,
i.e. from the shipped survey artifact, so the figures plot exactly the numbers
the pipeline produced. Rerun with:

```bash
.venv/bin/python figures/make_validation_figures.py
```

| File | What it is | Use for |
| --- | --- | --- |
| `Fig_diet_validation.{png,pdf}` | R22-354: 4 chow vs 4 NASH, one staining run | **the validation figure** — the only external ground truth the arm has |
| `Fig_nine_batches.{png,pdf}` | 259 slides across 9 staining runs, per-slide | the generalisation figure |

Both use a log x-axis, labelled as such, because the claim is about orders of
magnitude and on a linear axis every negative slide collapses onto the spine —
which is the range the specificity argument lives in. Every slide is a dot and
there are no box plots: at n=4 a box draws quartiles through four points and
implies a distribution that was never measured.

Blue/orange is the validated categorical pair (CVD ΔE 24.7, well clear of the
≥8 gate). In `Fig_nine_batches` row position already encodes batch, so nine
hues would encode it twice; only the negative control is coloured, because it
is the one row that means something different.

## Captions — ready to paste

**Fig_diet_validation.** Macrovesicular fat fraction measured by the
pseudo-labelling pipeline on the eight R22-354 slides, the only slides in the
260-slide collection whose filenames record diet and which were all cut and
stained in a single run on 2025-03-28. Detector parameters were tuned on a
different cohort and the detector had not previously been run on any of these
slides. Chow-fed animals (blue) read 0.07–0.20% and NASH-diet animals (orange)
7.58–10.46%: complete separation, AUC 1.000, Mann–Whitney p = 0.029, with the
lowest NASH slide 37.5× the highest chow slide. Genotype is balanced, two WT
and two ACLY656 per diet. Grey band, the range of the CCl₄ negative control
(n=37, 0.04–0.34%); untreated liver falls inside it. Four animals per group, so
p = 0.029 is the smallest value this design can produce. Log axis.

**Fig_nine_batches.** Per-slide macrovesicular fat fraction for 259 slides
across nine staining runs spanning 2025-03-07 to 2026-04-20, measured with
`configs/tuned.yaml` unchanged; the pipeline had been tuned on two of these
runs and had never been applied to the other seven. Each dot is one slide
(vertical jitter only); the vertical rule is the batch median; rows are ordered
by median. The CCl₄ cohort (orange) is a fibrosis model carrying no steatosis
and reproduces its previously reported false-positive floor at 0.17% mean /
0.34% worst slide. No batch collapses to zero or saturates, and six of the nine
contain both a slide below 1% and one above 5%, so severity varies within
staining run as well as between. Log axis. Absolute fat fractions are
uncalibrated (see LIMITATIONS.md §1); relative comparisons under identical
parameters are the supported reading.
