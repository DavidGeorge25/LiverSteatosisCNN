# Grant figures — steatosis pseudo-labeling

Generated by `make_figures.py` from `outputs/dataset_v1/`, i.e. from the exported
label set itself, so the panels show exactly the labels the pipeline ships.
Rerun with:

```bash
.venv/bin/python figures/make_figures.py
```

## Files

| File | What it is | Use for |
| --- | --- | --- |
| `Fig_steatosis_pseudolabels.{png,pdf}` | 3 tissue types × (H&E / pseudo-label) | **the main one** — send this |
| `Fig_steatosis_pair.{png,pdf}` | one field, H&E next to pseudo-label | tight space, or a single-column slot |
| `Fig_steatosis_confidence.{png,pdf}` | H&E / pseudo-label / ensemble confidence | if the weak-supervision angle needs making |
| `panels/*.png` | the individual panels at native 512 px | re-laying-out the figure in Illustrator |

PNG is 600 dpi. PDF carries live text (TrueType-embedded), so panel labels can be
restyled without re-rendering the histology.

All 512 × 512 px, level 0, 0.4953 µm/px (20× objective). Scale bar 50 µm.

Panels were chosen by `select_panels.py`, which ranks candidate tiles by how much
unambiguously droplet-like white space the label misses, rather than by eye. Two
of the three panels deliberately contain the structures most easily mistaken for
fat — a portal vessel lumen (moderate) and pale rarefied cytoplasm (control) —
both correctly rejected.

## What these figures do and do not support

Safe to claim:

- Pseudo-labels are generated **without any manual annotation**.
- **Specificity is measured**, not asserted: 0.17% mean fat area on a cohort
  known to be fat-free, worst slide 0.44% (`outputs/batch_CCl4_tuned2.csv`).
- **Perfect slide-level separation** of the two cohorts, which survives 200
  held-out splits (`outputs/holdout_repeats.csv`).
- Labels carry a **per-pixel confidence** map usable as a loss weight.

Not supported by anything here — do not put these in the grant:

- Any accuracy figure (Dice/IoU/precision/recall). There is no reference
  segmentation, so none can be computed.
- Absolute fat percentages as calibrated measurements. The parameter sweep moves
  cohort mean fat over 6.82–10.91% while separation stays saturated at AUC 1.000;
  slide-resampled mean is 9.4%, 95% CI [7.18, 11.40]. Relative comparisons
  between slides under identical parameters are well supported; absolute values
  are not.
- Sensitivity. The negative control bounds false positives only; there is no way
  here to measure what the pipeline misses.
- Microvesicular steatosis. Measured but excluded from labels — it separates the
  cohorts only ~1.4:1. **Scope is macrovesicular only** and should be stated.
